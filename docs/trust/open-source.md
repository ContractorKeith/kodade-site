# Open source and licensing

ködade is open source under the
[Apache License 2.0](https://github.com/Kodade/kodade/blob/main/LICENSE). The
public app has no paid feature tier, required ködade account, or production
license token.

The source, issue tracker, release history, and contribution guide live in the
[Kodade/kodade repository](https://github.com/Kodade/kodade). Third-party
components retain their own licenses and notices.

## Trademark boundary

Apache-2.0 covers the code. It does not grant rights to the ködade name, logo,
or other brand assets. See the repository's
[trademark policy](https://github.com/Kodade/kodade/blob/main/TRADEMARK.md) for
the permitted uses.

## Development source is not a supported feature

The repository can contain experimental work that is intentionally excluded
from public release builds. Its presence in the source tree does not make it a
supported app feature. The current boundary is listed in [Platform and release
status](../support/platform-status.md).
